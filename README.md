# OpenCV Image Processing

Computer vision lab work in C++ with OpenCV.

## Features

- Grayscale conversion and thresholding
- Noise reduction with median blur
- Contour detection and shape analysis
- Ellipse fitting for object detection

## Tech stack

C++, OpenCV, Visual Studio

## Getting started

Open `test_rooz.vcxproj` in Visual Studio with OpenCV configured, and set the image path in the source file.
